MORE THAN A TEMPERATURE

A small weather desk.
A sky with some life.

Keep the forecast running on your desktop, or let it take over as your screensaver.

01 / FORECAST

Plan the next few days.

Current conditions, today and tonight, a 12-hour outlook and a seven-day forecast. Details include gusts, humidity, dew point, visibility, pressure and UV when available.

02 / ATMOSPHERE

Weather you can settle into.

Animated day and night skies, clouds, fog, drizzle, rain, snow and thunderstorms. Optional original ambient sound matches the scene.

03 / DISPLAY

Old screens welcome.

A native Windows renderer with adjustable quality. CRT Mode combines larger, bolder text, lightweight scenery and a safe text inset while filling the output raster.

04 / THE EVERYDAY

A little useful extra.

Time and date, sun and moon information and upcoming US holidays. Choose the pages, their order and how long each stays on screen.

UP AND RUNNING

Install. Add a ZIP.
Watch the weather.

The installer includes the player and an optional Windows screensaver. Existing app windows close gracefully during upgrades; saved preferences and locations are retained.

Download the v1.2.1 installer ↓
  1. 1

    Install the player

    Download and run the Windows installer. It is unsigned; Windows may show an unknown-publisher or SmartScreen warning. Check the published SHA-256 before deciding to run it.

  2. 2

    Choose your location

    Open Weather → Add or Change Location and enter a US ZIP code. Live requests go directly to the weather and location providers.

  3. 3

    Make it yours

    Select a background, choose pages or enable CRT Mode. Press F11 for fullscreen. In the screensaver, audio starts disabled; M enables or disables it without exiting.

BEFORE YOU DOWNLOAD

Clear about the details.

Which Windows versions does it support?

The 32-bit build targets Windows XP SP3 through Windows 11, with a Pentium III CPU target. This is a compatibility target, not certification of every system. The parent v1.2 build was user-tested on a Dell Inspiron 6400 / Core 2 Duo T7400 / ATI X1300 with XP and a 720×480 CRT output. Version 1.2.1 has also been confirmed stable by the project maintainer.

Is everything free and open source?

The original player, generated art and synthesized ambience use the MIT license. Third-party components retain their own licenses, and matching network-helper source is provided. There is no purchase price, advertising or subscription. Open-Meteo's free hosted API is for noncommercial use and has limits; its service terms are separate from the software license.

Does it prevent screen burn-in?

Scenery movement and periodic foreground shifts reduce static content. They do not guarantee prevention of burn-in. Use your display's normal care and power settings.

Why might Windows warn about the installer?

This release is unsigned and may be unfamiliar to Windows. A checksum verifies that a download matches the published file; it does not establish that software is harmless. Source and build instructions are available for inspection.

Where does weather and location information come from?

Weather data by Open-Meteo, under CC BY 4.0. The app selects, rounds, converts and summarizes forecast values. Location lookup uses Zippopotam.us with data from GeoNames. Zippopotam.us identifies ODbL database terms and DbCL contents terms. Forecasts are model based; this is not an alert service.
